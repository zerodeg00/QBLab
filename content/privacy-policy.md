큐비랩(https://qblab.kr, 이하 "사이트")은 정보주체의 자유와 권리 보호를 위해 「개인정보 보호법」 및 관계 법령이 정한 바를 준수하여 개인정보를 적법하게 처리하고 안전하게 관리하고자 노력합니다. 이에 따라 사이트 운영 과정에서 실제로 이루어지는 개인정보 처리 현황과 정보주체의 권리 행사 방법을 아래와 같이 공개합니다.

사이트는 회원가입, 유료 결제, 뉴스레터 발송, 상담 신청 폼을 운영하지 않습니다. 따라서 운영자가 별도의 회원 DB를 직접 구축하여 관리하지는 않으며, 방문 통계, 광고, 댓글, 공유, 조회수 집계에 필요한 범위에서만 개인정보 또는 개인정보와 결합될 수 있는 정보를 처리합니다.

<h2 id="purpose">1. 개인정보의 처리 목적</h2>

사이트는 다음 목적 범위에서 개인정보를 처리합니다. 처리하고 있는 개인정보는 아래 목적 외의 용도로 이용되지 않으며, 이용 목적이 변경되는 경우에는 관계 법령에 따라 필요한 조치를 이행하겠습니다.

- 사이트 접속 제공 및 보안 유지
- 방문 통계 분석과 콘텐츠 개선
- 광고 게재, 광고 성과 측정, 부정 클릭 방지
- 페이지 조회수 집계
- 댓글 기능 제공
- 카카오 공유 기능 제공
- 오류 대응, 서비스 안정성 확보 및 기본적인 악용 방지

<h2 id="items">2. 처리하는 개인정보의 항목</h2>

사이트가 실제로 처리하는 개인정보 항목은 다음과 같습니다.

| 구분 | 처리 항목 |
| --- | --- |
| 사이트 접속 및 기본 로그 | IP 주소, 접속 일시, 요청 URL, 리퍼러, 브라우저 종류, 운영체제, 기기 정보 |
| 방문 통계 분석 (`Google Analytics`) | 방문 페이지, 체류 및 이벤트 정보, IP 기반 대략적 위치 정보, 브라우저/기기 정보, 쿠키 또는 유사 식별자 |
| 광고 게재 및 측정 (`Google AdSense`) | 광고 요청·응답 정보, 광고 노출 및 반응 정보, IP 기반 대략적 위치 정보, 브라우저 정보, 쿠키 또는 광고 식별자 |
| 조회수 집계 (`Firebase Realtime Database`) | 페이지 경로, 일자별/전체 누적 조회수, 최근 집계 시각을 저장하는 브라우저 저장소 값(`localStorage`) |
| 댓글 (`giscus` / `GitHub`) | GitHub 계정 식별정보, 프로필 정보, 댓글 내용, 댓글 작성 시각, GitHub가 서비스 제공 과정에서 처리하는 부가 정보 |
| 공유 (`Kakao SDK`) | 공유 대상 페이지 URL, 제목, 썸네일 등 메타데이터와 공유 기능 동작에 필요한 접속 정보 |

사이트 운영자는 이름, 전화번호, 주민등록번호, 결제정보와 같은 정보를 직접 입력받는 폼을 운영하지 않습니다. 다만 이용자가 댓글 기능 등 외부 서비스를 사용할 경우, 해당 서비스 사업자가 이용자의 브라우저로부터 필요한 정보를 직접 수집·처리할 수 있습니다.

<h2 id="retention">3. 개인정보의 처리 및 보유 기간</h2>

사이트는 원칙적으로 개인정보 처리 목적이 달성된 후에는 지체 없이 해당 정보를 파기합니다. 다만 실제 보유 기간은 처리 주체별로 다음과 같이 구분됩니다.

| 구분 | 보유 기간 |
| --- | --- |
| 운영자가 직접 별도로 보유하는 회원 DB | 해당 없음 |
| 페이지뷰 쿨다운 값(`localStorage`) | 동일 페이지의 최근 집계 시각이 브라우저 저장소에 보관되며, 이용자가 직접 삭제할 때까지 또는 브라우저 저장소 정책에 따라 유지 |
| Firebase 기반 조회수 누적 수치 | 서비스 운영 기간 동안 또는 운영자가 집계 데이터를 삭제할 때까지 |
| `giscus` / `GitHub` 댓글 정보 | 이용자 또는 운영자가 댓글을 삭제할 때까지, 또는 GitHub 정책에 따른 기간까지 |
| `Google Analytics`, `Google AdSense`를 통해 처리되는 쿠키·로그·광고 식별자 | 각 서비스 제공자의 정책 및 계정 설정에 따른 기간까지 |

운영자는 별도의 회원 DB를 직접 보유하지 않으므로, 외부 서비스 사업자가 처리하는 정보의 세부 보유 기간은 각 사업자의 정책을 함께 참고하시기 바랍니다.

<h2 id="destruction">4. 개인정보의 파기 절차 및 방법</h2>

사이트 운영자가 직접 보유하는 개인정보가 발생한 경우에는 처리 목적 달성 후 지체 없이 파기합니다. 파기 절차 및 방법은 다음과 같습니다.

1. 파기 절차
운영자가 직접 보유 중인 정보가 처리 목적 달성, 보유 기간 경과, 서비스 종료 등으로 불필요하게 된 경우 지체 없이 삭제 또는 파기합니다.

2. 파기 방법
- 전자적 파일 형태의 정보는 복구 또는 재생이 불가능한 방법으로 삭제합니다.
- 출력물이나 서면 자료는 분쇄 또는 소각합니다.
- 브라우저에 저장된 쿠키, 로컬 스토리지, 세션 스토리지는 이용자가 직접 삭제할 수 있습니다.

<h2 id="third-party">5. 개인정보의 제3자 제공에 관한 사항</h2>

사이트 운영자는 운영자가 별도로 보유한 개인정보를 판매하거나 독자적인 DB 형태로 제3자에게 제공하지 않습니다.

다만 이용자가 사이트에 접속하거나 댓글, 광고, 공유 기능을 사용하는 과정에서는 이용자의 브라우저가 `Google`, `GitHub`, `Kakao` 등 외부 사업자의 서버와 직접 통신할 수 있으며, 이 경우 각 사업자가 자체 개인정보 처리방침에 따라 개인정보를 처리할 수 있습니다. 관련 내용은 아래 `6. 개인정보 처리업무의 위탁`, `7. 개인정보의 국외 수집 및 이전`, `10. 제3자의 행태정보 수집·이용` 항목을 참고하시기 바랍니다.

<h2 id="outsourcing">6. 개인정보 처리업무의 위탁에 관한 사항</h2>

사이트는 원활한 서비스 제공을 위해 아래 외부 사업자의 도구 또는 인프라를 사용하고 있습니다.

| 수탁자 또는 서비스 제공자 | 위탁 또는 제공받는 업무 |
| --- | --- |
| `Google LLC` | 방문 통계 분석, 광고 게재 및 측정, 조회수 집계 인프라 제공 (`Google Analytics`, `Google AdSense`, `Firebase`) |
| `GitHub, Inc.` (`giscus`) | 댓글 기능 제공 |
| `Kakao Corp.` | 카카오 공유 기능 제공 |

사이트 운영자는 필요한 경우 외부 사업자와의 서비스 이용 관계에서 개인정보가 안전하게 처리되도록 관련 정책과 보안 기능을 확인하며, 위탁 또는 이용 관계가 변경되는 경우 본 방침을 지체 없이 갱신하겠습니다.

<h2 id="overseas">7. 개인정보의 국외 수집 및 이전에 관한 사항</h2>

사이트 운영자는 운영자가 보유한 회원 DB를 별도로 국외 서버로 이전하지 않습니다. 다만 아래 외부 서비스를 로드하거나 이용하는 과정에서 정보가 국외에서 직접 수집·처리되거나 국외 서버에 저장될 수 있습니다.

| 서비스 | 이전 또는 처리 항목 | 이전 국가 / 시기 / 방법 | 이전받는 자 | 목적 / 보유기간 | 거부 방법 및 영향 |
| --- | --- | --- | --- | --- | --- |
| `Google Analytics`, `Google AdSense` | IP 주소, 방문 페이지, 접속 시각, 브라우저/기기 정보, 쿠키 또는 광고 식별자, 광고 반응 정보 | 사이트 접속 시 HTTPS 통신을 통해 `Google` 서버로 전송될 수 있으며, 미국 및 Google이 서비스를 운영하는 국가에서 처리될 수 있습니다. | `Google LLC` | 방문 통계 분석, 광고 게재 및 측정, 부정 이용 방지 / 보유기간은 Google 정책 및 계정 설정에 따름 | 브라우저 쿠키 차단, `Google 광고 설정`, `Google Analytics` 차단 도구 사용 가능. 일부 광고·통계 기능이 제한될 수 있습니다. |
| `Firebase Realtime Database` | 페이지 경로, 누적 조회수 집계 정보 | 페이지 로딩 및 최초 집계 시 HTTPS 통신을 통해 미국 `us-central1` 리전(아이오와) 데이터베이스로 전송될 수 있습니다. | `Google LLC` | 페이지 조회수 집계 / 운영자가 삭제할 때까지 | 스크립트 차단 또는 브라우저 저장정보 삭제 시 조회수 집계가 제한될 수 있습니다. |
| `giscus` / `GitHub` | GitHub 계정 정보, 프로필 정보, 댓글 내용 | 댓글 위젯 사용 시 HTTPS 통신을 통해 GitHub의 지역 서버, 미국 및 기타 운영 국가로 전송될 수 있습니다. | `GitHub, Inc.` | 댓글 기능 제공 / 댓글 삭제 또는 GitHub 정책에 따름 | 댓글 기능을 사용하지 않으면 전송되지 않습니다. 이미 작성한 댓글은 GitHub 또는 giscus에서 삭제해야 합니다. |

국외 처리와 관련한 보다 자세한 사항은 각 사업자의 정책을 참고하시기 바랍니다.

- [Google 개인정보처리방침](https://policies.google.com/privacy)
- [Firebase Realtime Database 위치 안내](https://firebase.google.com/docs/database/locations)
- [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

<h2 id="security">8. 개인정보의 안전성 확보조치에 관한 사항</h2>

사이트는 개인정보의 안전성 확보를 위하여 다음과 같은 조치를 취하고 있습니다.

- 운영자가 직접 보유하는 개인정보를 최소화하고, 별도의 회원 DB를 운영하지 않습니다.
- 관리자 콘솔 접근 권한은 운영자 계정으로 제한하고, 외부 서비스 사업자가 제공하는 인증·권한관리 기능을 활용합니다.
- 사이트는 HTTPS를 통해 통신하며, 외부 서비스의 암호화 전송 기능을 사용합니다.
- 사이트 코드와 설정을 점검하고, 불필요한 수집 기능을 두지 않도록 관리합니다.

<h2 id="cookies">9. 개인정보 자동 수집 장치의 설치·운영 및 거부에 관한 사항</h2>

사이트는 쿠키, 세션 스토리지 등 자동 수집 장치를 사용할 수 있습니다.

1. 사용 목적
- 방문 통계 분석
- 광고 게재 및 광고 성과 측정
- 세션 중복 조회수 방지
- 기본적인 사이트 동작 유지

2. 사용 항목
- 쿠키 및 유사 식별자
- 브라우저가 자동 전송하는 접속 기록
- `localStorage`에 저장되는 최근 집계 시각

3. 거부 방법
- `Chrome`: 우측 상단 `⋮` → `새 시크릿 창`, 또는 설정 → `개인정보 보호 및 보안`
- `Edge`: 우측 상단 `...` → `새 InPrivate 창`, 또는 설정 → `쿠키 및 사이트 권한`
- 모바일 `Chrome`: 우측 상단 `⋮` → `새 시크릿 탭`
- `Samsung Internet`: 하단 `탭` → `비밀 모드 켜기`

이용자가 쿠키 저장을 거부하거나 삭제할 경우 광고 개인화, 댓글 유지, 조회수 중복 방지, 방문 통계 등 일부 기능이 정상적으로 동작하지 않을 수 있습니다.

<h2 id="behavioral">10. 제3자의 행태정보 수집·이용 및 거부에 관한 사항</h2>

사이트는 `Google AdSense` 및 `Google Analytics`를 사용하고 있으므로, 제3자인 `Google`이 쿠키와 유사 기술을 통해 행태정보를 수집·이용할 수 있습니다.

- 수집될 수 있는 항목: 방문 페이지, 접속 시각, 리퍼러, 브라우저/기기 정보, 광고 노출 및 반응 정보, 쿠키 또는 광고 식별자, IP 기반 대략적 위치 정보
- 이용 목적: 광고 게재, 광고 성과 측정, 부정 클릭 방지, 방문 통계 분석, 콘텐츠 개선
- 보유 기간: `Google` 정책 및 계정 설정에 따름
- 거부 방법:
  - [Google 광고 설정](https://adssettings.google.com/)
  - [Google Analytics 차단 브라우저 부가 기능](https://tools.google.com/dlpage/gaoptout)
  - 브라우저에서 제3자 쿠키 차단 또는 전체 쿠키 삭제
